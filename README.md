# DAA Assignment 3 - Graphs

Java 17 / Maven project for City Network & Job Scheduler.

The shared adjacency-list graph supports directed and undirected weighted graphs,
including parallel edges, self-loops, isolated vertices and disconnected graphs.

Build and run the JUnit 5 tests with `mvn clean verify`.

Implementation and documentation are being added in small feature commits.
